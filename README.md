 The Nigeria States Location Project 🇳🇬

An interactive Python game built using the **Turtle** graphics module and the **Pandas** library. Test your geography 
knowledge by naming all 36 states in Nigeria! When you guess a state correctly, its name automatically writes onto its exact
coordinate on the map.

---

 🌟 Features

* **Interactive Graphical Interface:** Built using Python's `turtle` module to render a detailed map of Nigeria.
* **Data-Driven Coordinate Mapping:** Uses `pandas` to read state names and (x, y) coordinates directly from a CSV dataset.
* **Real-time Map Updates:** Automatically writes correctly spelled state names directly onto their exact location on the map window.
* **Educational & Fun:** Tracks your score as you attempt to name all the states.

---

🛠️ Tech Stack & Requirements

* **Python 3.x**
* **Pandas** (for CSV data manipulation)
* **Turtle** (built-in Python GUI module for graphics and image handling)

---

 🚀 Getting Started

1. Clone the Repository
   https://github.com/theVictorOye/The-Nigeria-States-Location-Project.git

2. Install Dependencies
Make sure you have Pandas installed in your environment:
pip install pandas

3. Run the Game
Execute the main script to launch the GUI:
python main.py

🎮 How to Play

Run the program to display the interactive map window.

An input prompt will ask you to type the name of a Nigerian state.

If you spell the state name correctly:

The name will instantly appear on the map at its geographic coordinate.

Your score counter will increment.

Keep guessing until you locate all 36 states!
or press "exit" to quit.
